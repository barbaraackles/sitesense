# Drone survey photos

Drop your own drone photos (JPG/PNG/WebP) into this folder. The web UI's **Drone** tab and `python sitesense.py --drone samples/drone` pick up every image here. You can also multi-select many files in the browser upload.

The current images are openly licensed stand-ins; see `../CREDITS.md`. When you add your own, update CREDITS (or delete the stand-ins).
